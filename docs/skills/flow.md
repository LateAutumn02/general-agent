# Skills 流程

> 最后更新：2026-06-17 | 参考：legacy/python/docs/skills, reference/cc-haha/docs/skills

## 阶段1：发现技能

1. **扫描技能目录** - 读取用户级、项目级和插件提供的技能。
2. **解析元数据** - 读取名称、描述、触发词、允许工具和 prompt。
3. **构建命令索引** - `/skill-name` 可以直接触发。

## 阶段2：触发技能

1. **显式触发** - 用户输入 `/skill-name`。
2. **建议触发** - 后续可根据输入语义提示可用技能。
3. **注入上下文** - 将技能 prompt 作为用户请求或 system augmentation。

## 阶段3：执行和约束

1. **工具限制** - 技能可以收窄可用工具列表。
2. **资源加载** - 技能引用的模板和脚本按需加载。
3. **会话记录** - 记录技能触发事件，方便 resume。

## v1 简化流程

1. 支持本地 `skills/*/SKILL.md`。
2. 支持 `/skill-name`。
3. 自动触发后置。
