# 上下文压缩流程

> 最后更新：2026-06-17

## 阶段1：预算检查

1. **估算 token** - 每轮模型调用前估算 messages + system + tools。
2. **判断阈值** - 超过软阈值时优先做轻量折叠，超过硬阈值时触发 compact。
3. **保留近期上下文** - 最近用户意图、未完成工具调用和错误必须保留。

## 阶段2：轻量折叠

1. **工具结果折叠** - 搜索/读取类工具结果压缩为摘要。
2. **重复通知折叠** - 连续后台任务通知合并。
3. **大输出截断** - stdout/stderr 保留首尾和可定位信息。

## 阶段3：模型压缩

1. **构造压缩提示词** - 要求保留目标、决策、文件变更、未完成事项和用户偏好。
2. **生成摘要消息** - 用 summary 替换较老历史。
3. **写入 session** - compact 事件和摘要都可追踪。

## v1 简化流程

1. 先做工具结果折叠。
2. 再做手动 `/compact`。
3. 自动 compact 后置。
