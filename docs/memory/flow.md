# 记忆系统流程

> 最后更新：2026-06-17 | 参考：legacy/python/docs/memory, reference/cc-haha/docs/memory

## 阶段1：加载记忆

1. **发现记忆文件** - 读取用户级、项目级和本地级 memory 文件。
2. **过滤作用域** - 只加载当前 cwd 可访问的记忆。
3. **注入提示词** - 将记忆作为动态 system section 加入模型请求。

## 阶段2：使用记忆

1. **用户显式管理** - 支持 `/memory list/on/off/refresh`。
2. **Agent 查询记忆** - 后续可通过专用工具读取大记忆文件。
3. **自动提取** - v1 后置，避免过早引入误写风险。

## 阶段3：更新记忆

1. **生成候选记忆** - 从对话中提取稳定偏好或项目事实。
2. **用户确认** - 默认需要用户确认后写入。
3. **写入作用域文件** - 按 user/project/local 分类保存。

## v1 简化流程

1. 只读加载项目记忆。
2. 手动刷新。
3. 自动写入后置。
