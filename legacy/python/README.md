# general-agent

> 用 Python 实现的通用 AI Agent，当前主要参考 Anthropic Claude Code。

## 快速开始

```bash
pip install general-agent
glagent
```

首次运行会弹出配置向导，输入 API key 即可。

## 项目目的

开发一个功能完整的通用 AI Agent。参考 Claude Code 的核心架构与设计理念，用 Python 重新实现其关键能力，包括：

- **Agent 核心循环** — 对话驱动的主循环，支持多轮工具调用与自愈重试
- **工具系统** — 可扩展的工具注册、执行、权限控制
- **记忆系统** — 跨会话的长期记忆，支持自动提取与索引管理
- **Skills 系统** — 可插拔的技能扩展，支持 Inline 和 Fork 两种执行模式

## 分支规范

| 分支 | 用途 |
|---|---|
| `main` | 稳定运行的 baseline，每个 commit 都是可交付的版本 |
| `dev` | 开发分支，两个稳定大版本之间的增量开发都在此进行 |
| `feature/*` | 功能分支，单个功能独立开发，测试通过后汇入 dev |
| `release/*` | 发布分支，暂不考虑 |

## 提交规范

- 提交信息用**英文**编写，**简洁明了**，描述本次改动的实际内容
- 禁止在提交信息中写入无关废话（如"Generated by Claude"、"Co-Authored-By" 等工具签名）
- 推荐格式：`<type>: <description>`，例如 `feat: add tool registration system`、`fix: handle empty skill directory`
- **提交和推送前必须经用户同意**，展示待提交/推送的文件和变更摘要，用户确认后方可执行

## 开发流程

1. **创建分支** — 从 `dev` 切出 `feature/<功能名>` 分支
2. **查阅文档** — 阅读 `docs/` 中对应模块的流程和数据结构文档，以及参考项目的源代码
3. **补齐文档** — 如果该功能还没有设计文档，先从参考项目中学习分析，按规范补齐文档后再开始编码
4. **实现功能** — 尽量完整保留参考项目的所有功能。当前版本不便实现或暂时不需要的，先写好函数骨架并注释保留，后续视情况补齐
5. **测试** — 完成代码后进行单元测试和整体回归测试
6. **更新文档** — 根据实际代码逻辑修改完善对应的 docs 文档，始终保持文档与代码一致
7. **总结汇报** — 告知功能开发进度、测试效果，以及与参考项目的详细差异及原因
8. **提交前确认** — 展示待提交的文件和变更摘要，经用户同意后再 commit
